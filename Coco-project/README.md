# Coco AI Chatbot

Coco is a premium glassmorphism AI chatbot designed to be an intelligent, multilingual assistant.

## Features
- General-purpose AI assistant powered by OpenAI.
- Supports any language, automatically detecting the user's language.
- Short, Medium, and Long response length options.
- Premium glassmorphism UI built with React, Vite, and Tailwind CSS.
- Robust Node.js & Express backend.
- PostgreSQL database via Supabase.

## Setup
Run `scripts/setup.sh` or install dependencies manually.
